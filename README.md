# Dra. Paloma Azevêdo — prévia conceitual

Execute `npm install` e `npm run dev`. A fonte Allo está configurada como dependência npm e importada no JS. Para publicar, execute `npm run build` e envie o conteúdo de dist/ à subpasta paloma-azevedo do servidor. Não foram incluídos arquivos de fonte nem imagens geradas. As fotos reais usam URLs do site original, sujeitas a disponibilidade e autorização. A instalação e o teste visual não puderam ser executados devido à falta de conexão externa. O símbolo do cabeçalho é conceitual, não o logotipo oficial. A página usa noindex,nofollow para evitar indexação da prévia. Validar CRM/RQE, textos do programa, fotos e identidade antes da publicação oficial.
